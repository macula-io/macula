# E2E seal, scheme 1: the byte-exact construction

The contract every Macula SDK implements for end-to-end payload confidentiality
(`plans/DESIGN_E2E_PAYLOAD_CONFIDENTIALITY.md`, §13 #1). `e2e_seal_v1.json`
holds the vectors: an SDK passes when it reproduces every output from every
input. The vectors are generated by `scripts/e2e_seal_vectors` (Rust, on
`macula-mlkem`, RustCrypto `p384`, `hkdf`, `aes-gcm`) and checked by macula's
Erlang implementation (`macula_seal`, on OTP `crypto`). Two independent
implementations agree on them.

## Notation

- `cbor([a, b, ...])`: the deterministic CBOR array of the items, in order.
  Byte strings are CBOR byte strings (major type 2). Labels and names are CBOR
  text strings (major type 3). Integers are unsigned, in the shortest form.
  This is what makes every concatenation in the design unambiguous.
- `HKDF-Extract` and `HKDF-Expand`: RFC 5869 with HMAC-SHA-384. A PRK is 48
  bytes.
- `SEAL(k, nonce, aad, pt)`: AES-256-GCM, 12-byte nonce, 16-byte tag appended
  to the ciphertext. `OPEN` is its inverse and fails on any mismatch.

## Keys

- **ML-KEM-1024** (FIPS 203): the encapsulation key `ek` is 1568 bytes, and a
  ciphertext is 1568 bytes. A vector gives the key's seed `d || z` (64 bytes,
  the form Go's `crypto/mlkem` loads) and the expanded decapsulation key `dk`
  (3168 bytes, the form OTP's `crypto` loads). Both are the same key.
- **P-384** (pq_hybrid only): points uncompressed, 97 bytes. A private scalar
  is 48 bytes.
- **The recipient's KEM key as carried:** `ek` in pq_pure; `ek || p384_pub` in
  pq_hybrid.
- `recipient_key_hash = SHA-384(the key as carried)`, 48 bytes;
  `key_id = recipient_key_hash[0..8]`.

## The shared secret

pq_pure:

```
ss_mlkem, mlkem_ct = ML-KEM-1024.Encaps(ek)                 (vector: m fixed)
ikm = cbor([ss_mlkem, mlkem_ct, recipient_key_hash])
ss  = HKDF-Extract(salt = "MACULA-E2E-PURE-V1", ikm)
kem_ct = mlkem_ct                                          (1568 bytes)
```

pq_hybrid adds an ephemeral P-384 ECDH with the recipient's P-384 key:

```
ss_ecdh = x coordinate of eph_priv * recipient_p384_pub     (48 bytes)
ikm = cbor([ss_mlkem, ss_ecdh, mlkem_ct, eph_pub, recipient_key_hash])
ss  = HKDF-Extract(salt = "MACULA-E2E-HYBRID-V1", ikm)
kem_ct = mlkem_ct || eph_pub                               (1568 + 97 bytes)
```

The recipient validates `eph_pub` as a point on P-384 and refuses an ECDH
output of all zeros.

## Call and stream keys

```
okm   = HKDF-Expand(ss, cbor(["MACULA-E2E-CALL-V1", frame_type, request_id, caller, target]), 64)
k_req = okm[0..32]    k_rep = okm[32..64]
```

`frame_type` is `"call"` or `"stream_open"`. A STREAM_OPEN also derives:

```
okm   = HKDF-Expand(ss, cbor(["MACULA-E2E-STREAM-V1", request_id, caller, target]), 64)
k_c2p = okm[0..32]    k_p2c = okm[32..64]
```

## AAD and nonces

| Sealed | Key | Nonce | AAD |
|---|---|---|---|
| CALL / STREAM_OPEN payload | `k_req` | 12 zero bytes | `cbor(["MACULA-E2E-AAD-V1", frame_type, realm, procedure, caller, target, request_id, deadline])` |
| RESULT / ERROR payload | `k_rep` | 12 random bytes, carried | `cbor(["MACULA-E2E-AAD-V1", reply_frame_type, realm, procedure, caller, target, request_id, deadline, request_hash, responded_by])` |
| Caller stream frame | `k_c2p` | `seq` as 96-bit big-endian | `cbor(["MACULA-E2E-STREAM-AAD-V1", frame_type, request_id, seq, 0])` |
| Provider stream frame | `k_p2c` | 12 random bytes, carried | `cbor(["MACULA-E2E-STREAM-AAD-V1", frame_type, request_id, seq, 1])` |
| Event | `k_pub` | 12 random bytes, carried | `cbor(["MACULA-E2E-EVENT-AAD-V1", realm, topic, publisher, seq, published_at])` |

`procedure` and `topic` are text; `realm`, `caller`, `target`, `request_id`,
`request_hash`, `responded_by` and `publisher` are byte strings; `deadline`,
`seq` and `published_at` are unsigned integers.

An event's key is the publisher's subkey of the group epoch key `k_g`:

```
prk_g = HKDF-Extract(salt = "MACULA-E2E-EVENT-V1", ikm = k_g)
k_pub = HKDF-Expand(prk_g, cbor(["MACULA-E2E-EVENT-V1", publisher]), 32)
```

(`k_g` is 32 bytes. RFC 5869 wants a PRK of at least 48 bytes, hence the
Extract.)

## The `sealed` map

`sealed = #{scheme => 1, key_id, ct}` plus `kem_ct` on a CALL or STREAM_OPEN,
and `nonce` where the table says the nonce is carried. The vectors give `ct`,
the ciphertext with its tag appended.
